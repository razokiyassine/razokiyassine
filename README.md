## Featured projects

### 01 · Defense-in-Depth Enterprise Lab
**Completed internship lab · Webal Prod · July–August 2026**

A segmented enterprise environment built and evaluated in an isolated VMware laboratory.

- Designed security zones and deny-by-default filtering with **pfSense**.
- Integrated **Suricata IDS**, an **Apache reverse proxy**, and **ModSecurity + OWASP CRS**.
- Investigated excessive AD permissions and Kerberos service-account exposure using Windows security events.
- Validated remediation: SQL injection blocked with **HTTP 403**, unauthorized group changes denied, and Kerberos tickets moved from **RC4 to AES-256**.
- Added **Cisco Duo MFA** to a domain workstation and documented before/after evidence.

**Stack:** pfSense · Suricata · ModSecurity · OWASP CRS · Windows Server · Active Directory · Cisco Duo · Kali Linux · VMware

[**Explore the architecture, tests, and results →**](https://github.com/razokiyassine/defense-in-depth-lab)

### 02 · Network Intrusion Detection & Traffic Analysis
**Academic notebooks · Python & machine learning**

A collection of network-security coursework exploring traffic relationships and intrusion classification.

- Used **linear regression** to model network-traffic features and inspect prediction errors.
- Built **logistic regression** experiments for binary and multiclass intrusion classification.
- Worked with **NSL-KDD**, preprocessing pipelines, categorical encoding, and feature scaling.
- Evaluated models with regression metrics, classification reports, and confusion matrices.

**Stack:** Python · pandas · NumPy · scikit-learn · Matplotlib · Seaborn · Jupyter / Google Colab

[**Explore the notebooks →**](https://github.com/razokiyassine/Network-Intrusion-Detection)
